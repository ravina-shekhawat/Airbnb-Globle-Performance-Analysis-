# Airbnb Global Performance Dashboard

## About the Project

This project is an **Airbnb Global Performance Dashboard** built using Power BI. It provides an overview of Airbnb listings, reviews, room types, city-wise market share, ratings, average prices, and listing trends over time.

The main purpose of this project was to learn and practice different **Power BI features and dashboard-building techniques**.

## Technologies Used

* **Power BI** – Dashboard creation and data visualization
* **DAX** – Creating measures and calculations
* **Power Query** – Data cleaning and transformation
* **Data Modeling** – Building relationships and organizing the data model
* **Bookmarks** – Creating interactive dashboard views
* **Power BI Editing Features** – Formatting and customizing visuals, layouts, and dashboard elements

## Data Source

The dataset used in this project is provided by **Maven Analytics**.

## Learning & Project Approach

I followed a step-by-step tutorial by **Mansi Goyal** to build this dashboard.

At this stage, my main goal was **not to independently decide the business logic or the best visualization for every metric**, but to understand how Power BI works and gain hands-on experience with its features.

Through this project, I practiced:

* Working with Power BI visuals
* Creating and using DAX measures
* Data transformation with Power Query
* Data modeling
* Dashboard formatting and editing
* Creating interactive elements using **Bookmarks**
* Designing and organizing a multi-page dashboard
* Working with different types of charts and visualizations

This project helped me become more familiar with the **Power BI interface and its features**, which I can now build upon with my own analysis and projects.
